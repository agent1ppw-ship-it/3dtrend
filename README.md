# 3DTrend

Find trending 3D printed products across the web.

## Features

- 🔍 Search 3D printed products on Amazon, eBay, and Etsy
- 📊 Real-time marketplace results
- 💾 Save favorites for later
- 📈 Market trend insights
- 💳 Simple pricing (Free, Pro, Business)

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Vercel

## Getting Started

```bash
npm install
npm run dev
```
